B3FG011MP0Dépose - Repose : Segments de freins arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage préconisé
Figure : e5am0awd
[ 1] pince à cylindre de roue:Type FACOM T.243.
[ 2] pince de dépose-pose des ressorts de segments de freins:Type FACOM 196TS.
Figure : e5am0axd
[3] pince pour câble de frein de stationnement:Type FACOM D.79A.
2. Opération préliminaire
Débloquer les vis de roues.
Lever et caler l’arrière du véhicule.
Déposer les roues.
Desserrer le frein de stationnement .
Déposer le tambour de frein arrière .
3. Dépose
3.1. Segments de freins arrière
Figure : b3fm05jd
Désaccoupler le câble de frein de stationnement du levier ( en "a").
Figure : b3fm05kd
Placer l’outil [ 1] sur le cylindre de roue.
Déposer :
  • Les agrafes (4)
  • Le ressort supérieur (1) ; À l’aide de l’outil [ 2]
  • Le mécanisme de rattrapage de jeu (2)
  • Le ressort inférieur (5)
  • Le segment arrière (3)
  • Le segment avant (6)
3.2. Cylindre de roue
Prévoir l’écoulement du liquide de frein.
Figure : b3fm05ld
Désaccoupler et écarter le raccord ( en "b").
Obturer les orifices de part et d’autre.
Déposer :
  • Les vis (8)
  • Le cylindre de roue (7)
4. Nettoyer
IMPERATIF : Ne pas utiliser d’air comprimé pour nettoyer les freins.
4.1. 1ère possibilité
Nettoyer le plateau et le tambour de frein à l’aide d’un produit nettoyant frein recommandé.
Laisser sécher et égoutter.
Essuyer avec un chiffon en papier.
4.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué .
Contrôler et/ou remplacer (Si nécessaire ) :
  • L’étanchéité autour du piston (/)
  • Le bon état des protecteurs caoutchouc du cylindre récepteur de roue
  • L’état d’usure du tambour
5. Repose
IMPERATIF : Respecter les couples de serrage .
IMPERATIF : Aucune trace de graisse, d’huile, etc. ne doit être tolérée sur les tambours et les garnitures.
5.1. Cylindre de roue
Reposer :
  • Le cylindre de roue (7)
  • Les vis (8)
Accoupler le raccord ( en "b").
Serrer le raccord.
5.2. Segments de freins arrière
Figure : b3fm05md
Graisser légèrement les 6 points d’appui "c" des segments de freins sur le plateau de frein.
Accoupler le câble de frein de stationnement au levier ( en "a") ; À l’aide de l’outil [3].
Reposer :
  • Le segment arrière (3)
  • L’agrafe (4)
  • Le segment avant (6)
  • Le ressort inférieur (5)
  • L’agrafe (4)
  • Le mécanisme de rattrapage de jeu (2)
  • Le ressort supérieur (1) ; (À l’aide de l’outil [ 2] )
Déposer l’outil [ 1].
6. Opération complémentaire
Reposer les tambours de frein arrière .
ATTENTION : Purger le circuit de freinage si échange du cylindre récepteur de roue .
Mettre le moteur en marche.
Appuyer plusieurs fois sur la pédale de frein.
Régler le frein de stationnement .
Reposer :
  • Les roues
  • Le véhicule sur ses roues
Serrer les vis de roue .
