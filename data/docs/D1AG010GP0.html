D1AG010GP0Dépose - repose : Alternateur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Mettre le véhicule sur un pont élévateur deux colonnes.
Débrancher la batterie .
Déposer :
  • La roue avant droite
  • La courroie d’entraînement des accessoires
  • Le galet enrouleur
1.1. Véhicule avec réfrigération
Figure : d1am037d
Déconnecter le connecteur du compresseur de réfrigération (2) (En "a").
Déposer les vis (1).
Écarter le compresseur de réfrigération (2) sans ouvrir le circuit de fluide.
1.2. Dépose (Suite)
Figure : d1am038d
Déposer :
  • Les vis (3)
  • L’écran thermique (4)
Figure : d1am039d
Déconnecter le connecteur de l’alternateur (En "c") (Suivant équipement).
Débrancher l’alimentation de l’alternateur (En "b").
Desserrer la vis (5).
Figure : d1am03ad
Desserrer la vis (7).
Déposer :
  • Les vis (8)
  • L’alternateur (6)
2. Repose
ATTENTION : Respecter les couples de serrage.
Reposer (Sans serrer) :
  • L’alternateur (6)
  • Les vis (8)
Serrer :
  • La vis (5)
  • La vis (7)
  • Les vis (8)
Rebrancher l’alimentation de l’alternateur (6) (En "b").
Connecter le connecteur de l’alternateur (6) (En "c") (Suivant équipement).
Reposer :
  • L’écran thermique (4)
  • Les vis (3)
2.1. Véhicule avec réfrigération
Reposer :
  • Le compresseur de réfrigération (2)
  • Les vis (1)
Connecter le connecteur du compresseur de réfrigération (2) (En "a").
2.2. Repose (Suite)
Reposer :
  • Le galet enrouleur
  • La courroie d’entraînement des accessoires
  • La roue avant droite
  • Le véhicule sur ses roues
Serrer les vis de roue.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
