C4AS0104P0Déshabillage - habillage : Capot moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage préconisé
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350-ZZ.
2. Opération préliminaire
Déposer le capot moteur .
3. Déshabillage
3.1. Emblème
Figure : c4am0dnd
Déclipper : L’emblème (1) ; À l’aide de l’outil [1].
3.2. Insonorisant de capot moteur
Figure : c4am0dpd
Épingler - Déclipper : Les agrafes  (en "a").
Déposer : L’insonorisant de capot moteur (2).
3.3. Gicleurs de lave-vitre
Figure : c4am0dqd
Déclipper les gicleurs de lave-vitre (3) ; À l’aide de l’outil [1].
Désaccoupler les tuyaux  (en "b") (Opération symétrique).
Déclipper :
  • Les tuyaux  (en "c", "d")
  • Les agrafes  (en "c", "d")
4. Habillage
4.1. Emblème
Clipper l’emblème (1).
4.2. Insonorisant de capot moteur
Reposer : L’insonorisant de capot moteur (2).
Clipper les agrafes  (en "a").
4.3. Gicleurs de lave-vitre
IMPERATIF : Prévoir le remplacement des agrafes .
Clipper :
  • Les agrafes  (en "c", "d")
  • Les tuyaux  (en "c", "d")
Accoupler les tuyaux  (en "b") (Opération symétrique).
Clipper : Les gicleurs de lave-vitre (3).
5. Opération complémentaire
Reposer le capot moteur .
Vérifier le fonctionnement des différents équipements.
