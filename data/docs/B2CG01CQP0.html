B2CG01CQP0Dépose - Repose : Électrovannes de l’actionneur de pilotage
BVM C510 PILOTE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
ATTENTION : Repérer les faisceaux électriques pour ne pas les intervertir à la repose.
ATTENTION : Effectuer la mise hors pression du circuit hydraulique de pilotage de la boîte de vitesses ; À l’aide d’un outil de diagnostic.
1. Opération préliminaire
Déposer :
  • La batterie
  • Le support batterie
  • Le raccord air du turbocompresseur
  • Le support de boîte de vitesses
  • La roue avant gauche
2. Dépose
2.1. Dépose : Électrovannes de passage des vitesses
Figure : b2cg1pnd
Déconnecter : Les connecteurs (2).
Déposer :
  • Les vis (3)
  • Les électrovannes (1)
NOTA : Obturer l’emplacement des électrovannes à l’aide de bouchons afin d’éviter toute entrée d’impuretés dans le circuit hydraulique.
2.2. Dépose : Électrovannes de commande de sélection de vitesses
Figure : b2cg1pqd
Déconnecter : Les connecteurs (4).
Déposer :
  • Les vis (5)
  • Les électrovannes (6)
NOTA : Obturer l’emplacement des électrovannes à l’aide de bouchons afin d’éviter toute entrée d’impuretés dans le circuit hydraulique.
2.3. Dépose : Électrovanne d’embrayage
Figure : b2cg1ptd
Déconnecter le connecteur (7).
Déposer :
  • Les vis (9)
  • L’électrovanne (8)
NOTA : Obturer l’emplacement de l’électrovanne à l’aide d’un bouchon afin d’éviter toute entrée d’impuretés dans le circuit hydraulique.
3. Repose
ATTENTION : Respecter les couples de serrage.
IMPERATIF : Remplacer systématiquement les joints des électrovannes.
3.1. Repose : Électrovannes de passage
Reposer :
  • Les électrovannes (1)
  • Les vis (3)
  • Reconnecter : Les connecteurs (2)
3.2. Repose : Électrovannes de commande de sélection de vitesses
Reposer :
  • Les électrovannes (6)
  • Les vis (5)
  • Reconnecter : Les connecteurs (4)
3.3. Repose : Électrovanne d’embrayage
Reposer :
  • L’électrovanne (8)
  • Les vis (9)
  • Reconnecter : Le connecteur (7)
Reposer :
  • La roue avant gauche
  • Le support de boîte de vitesses
  • Le raccord air du turbocompresseur
  • Le support batterie
  • La batterie
ATTENTION : Effectuer la mise sous pression et purge du circuit hydraulique ; À l’aide de l’outil diagnostic.
