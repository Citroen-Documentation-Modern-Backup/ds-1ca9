B2CG01CGP0Dépose - Repose : Calculateur de boîte de vitesses manuelle pilotée (Type MTA)
BVM C510 PILOTE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
ATTENTION : Lors de remplacement du calculateur de boîte de vitesses, effectuer une lecture des compteurs de boîte de vitesses ; À l’aide d’un outil de diagnostic. Enregistrer (noter) les informations concernant la boîte de vitesses.
1. Dépose
Débrancher la batterie.
NOTA : Le calculateur se trouve côté passager.
Figure : b2cg1oad
Déposer :
  • Le cache (1)
  • Les écrous (2)
  • Le cache (3)
Figure : b2cg1odd
Déposer : La vis de fixation (4) du calculateur.
Déconnecter les connecteurs  (en "a").
Déposer : Le calculateur .
2. Repose
Reposer : Le calculateur .
Reconnecter les connecteurs  (en "a").
Reposer :
  • La vis de fixation (4)
  • Le cache (3)
  • Les écrous (2)
  • Le cache (1)
Rebrancher la batterie.
Effectuer les séquences d’apprentissage :
  • Du calculateur de boîte de vitesses
  • De la boîte de vitesses
