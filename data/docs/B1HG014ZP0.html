B1HG014ZP0Dépose - repose : Réservoir à carburant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Vidanger le réservoir à carburant.
ATTENTION : Attendre au minimum une heure avant toute intervention sur la ligne d’échappement.
Déposer la ligne d’échappement .
Figure : b1hm0ggd
Déposer :
  • Les écrous (1)
  • L’écran thermique (2)
Figure : b1hm0ghd
Désaccoupler :
  • Les tubes (En "a")
  • Les tubes (En "b")
Figure : b1hm0gjd
Dégager : Les câbles de frein de stationnement (En "c").
Mettre en place la chandelle hydraulique.
Déposer les vis (3).
Descendre légèrement le réservoir à carburant .
Figure : b1hm0gkd
Déconnecter le connecteur (En "d").
Désaccoupler et obturer le tube d’alimentation de carburant (4).
Déposer le réservoir à carburant (5).
2. Repose
Présenter : Le réservoir à carburant (5) ; À l’aide d’une chandelle hydraulique.
Accoupler : Le tube d’alimentation de carburant (4).
Connecter le connecteur (En "d").
Engager : Les câbles de frein de stationnement (En "c").
Reposer :
  • Le réservoir à carburant (5)
  • Les vis (3) (serrage en croix)
Accoupler :
  • Les tubes (En "b")
  • Les tubes (En "a")
Reposer :
  • L’écran thermique (2)
  • Les écrous (1)
  • La ligne d’échappement
Remplir le réservoir.
