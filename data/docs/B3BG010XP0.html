B3BG010XP0Dépose - repose : Ensemble ressort - amortisseur avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie .
Débloquer les vis de roue avant.
Lever et caler le véhicule.
Déposer :
  • Les vis de roue avant
  • La roue avant
  • La grille d’auvent
Figure : b3bm042d
Dégrafer :
  • Les faisceaux électriques (en "a")
  • Le flexible de frein  (en "b")
Déposer l’écrou (1).
Désaccoupler la biellette (2) de la barre antidévers .
ATTENTION : Lors du dégagement de l’élément de suspension, maintenir la transmission dans le différentiel.
Déposer les vis (3).
Figure : b3bm043d
Déposer :
  • Les écrous (4)
  • L’ensemble ressort amortisseur avant
2. Repose
IMPERATIF : Respecter les couples de serrage .
ATTENTION : Remplacer systématiquement les écrous Nylstop.
Reposer :
  • L’ensemble ressort amortisseur avant
  • Les écrous (4)
  • Les vis (3)
Accoupler la biellette (2) de barre antidévers.
Reposer l’écrou (1).
Agrafer :
  • Le flexible de frein  (en "b")
  • Les faisceaux électriques (en "a")
Reposer :
  • La grille d’auvent
  • La roue avant
  • Le véhicule sur ses roues
Serrer les vis de roue .
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
