C4CH013HP0Remplacement : Panneaux de portes arrière battantes
IMPERATIF : Respecter les règles élémentaires d’hygiène et de sécurité (port du masque filtrant pour vapeurs organiques - travailler en zone ventilée).
ATTENTION : Toutes les surfaces décapées doivent être protégées par le procédé de rezingage électrolytique homologué .
1. Outillage préconisé
Figure : e5am00zd
Outils de sertissage de panneaux de portes (-).1130.
2. Opérations complémentaires
Panneau de porte arrière (Gauche ) :
  • Déshabiller : La porte arrière (Gauche )
  • Déposer la vitre de porte arrière (Gauche ) (selon équipement)
  • Déposer la porte arrière (Gauche )
Panneau de porte arrière (Droite) :
  • Déshabiller : La porte arrière (Droite)
  • Déposer la vitre de porte arrière (Droite) (selon équipement)
  • Déposer la porte arrière (Droite)

5. Nettoyage - Préparation : Doublure de porte
5.1. Doublure de porte battante arrière gauche
Figure : c4bm0lhd
Préparer les bords d’accostage .
Appliquer une colle structurale ( indice "B8") ( en "c").
Appliquer un mastic de calage ( indice "A1") ( en "d").
5.2. Doublure de porte battante arrière droite
Figure : c4bm0ljd
Préparer les bords d’accostage et les protéger par un apprêt soudable ( indice "C7") ( en "e").
Appliquer une colle structurale ( indice "B8") ( en "f").
Appliquer un mastic de calage ( indice "A1") ( en "g").
6. Ajustage
Positionner : Le panneau de porte .
Contrôler les jeux et affleurements.
Maintenir le panneau de porte en position.

Sertir le panneau de porte ; À l’aide des outils de sertissage (-).1130.
7.2. Soudage - Sertissage : Panneau de porte arrière (Droite)
Figure : c4bm0lld
Souder par points électriques ( en "h").
Sertir le panneau de porte ; À l’aide des outils de sertissage (-).1130.
8. Étanchéité protection
8.1. Panneau de porte arrière (Gauche )
Figure : c4bm0lmd
Appliquer un mastic d’étanchéité ( indice "A1").
Mise en peinture puis pulvérisation, dans les corps creux du produit indice C5, dans la zone de réparation.
8.2. Panneau de porte arrière (Droite)
Figure : c4bm0lnd
Appliquer un mastic d’étanchéité ( indice "A1").
Mise en peinture puis pulvérisation, dans les corps creux du produit indice C5, dans la zone de réparation.
9. Réinitialisation
Panneau de porte arrière (Gauche ) :
  • Reposer la porte arrière (Gauche )
  • Reposer la vitre de porte arrière (Gauche ) (selon équipement)
  • Habiller la porte (Arrière gauche)
Panneau de porte arrière (Droite) :
  • Reposer la porte arrière (Droite)
  • Reposer la vitre de porte arrière (Droite) (selon équipement)
  • Habiller la porte (Arrière droite)
