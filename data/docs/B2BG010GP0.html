B2BG010GP0Dépose - repose : Câble d’embrayage
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie .
Déposer :
  • La batterie (/)
  • Le support de batterie
Figure : b2bm01qd
Tirer sur le câble d’embrayage (1) (Suivant la flèche "a").
Dégager le câble d’embrayage du support arrêt de gaine (2).
Désaccoupler le câble d’embrayage (1) du levier de commande d’embrayage (3).
Figure : b2bm01rd
Déposer :
  • Les vis (4)
  • La garniture (5)
  • Les pions (6)
  • La garniture inférieure (7)
Figure : b2bm01sd
Déposer :
  • Les vis (8)
  • La prise de diagnostic (9)
Déconnecter les connecteurs ( en "b").
Dégrafer et écarter : Les faisceaux électriques.
Déposer les vis (12).
Déclipper et écarter le boîtier de servitude intelligent (11).
Déconnecter les connecteurs ( en "c").
Déposer le boîtier de servitude intelligent (11).
Figure : b2bm01td
Déposer :
  • Les vis (14)
  • Les écrous (13)
  • La patte (15)
Figure : b2bm01ud
Désaccoupler le câble d’embrayage (1).
Déposer le câble d’embrayage (1).
2. Repose
Engager le câble d’embrayage au travers du tablier.
Reposer :
  • La patte (15)
  • Les vis (14) (sans serrer)
Accoupler le câble d’embrayage (1) sur la pédale d’embrayage.
Reposer les écrous (13).
Serrer :
  • Les vis (14)
  • Les écrous (13)
Connecter les connecteurs ( en "c").
Clipper le boîtier de servitude intelligent (11).
Reposer les vis (12).
Agrafer les faisceaux électriques .
Connecter les connecteurs ( en "b").
Reposer :
  • La prise de diagnostic (9)
  • Les vis (8)
  • La garniture inférieure (7)
  • Les pions (6)
  • La garniture (5)
  • Les vis (4)
Engager le câble d’embrayage sur le support arrêt de gaine (2).
Tirer sur le câble d’embrayage (1).
Accoupler le câble d’embrayage sur le levier d’embrayage (3).
3. Réglage
ATTENTION : Appuyer plusieurs fois sur la pédale d’embrayage pour mettre l’ensemble en place.
Figure : b2bm01vd
Mesurer à l’aide d’un mètre les cotes L1 et L2 entre le milieu de la pédale et un même point du volant :
  • L1 position repos
  • L 2 pied au plancher
  • "X" = L2 - L1
Figure : b2bm01wd
Régler la course de la pédale d’embrayage "X" ; À l’aide de l’écrou (16).
"X" = 160 ± 7 mm .
Reposer :
  • Le support de batterie
  • La batterie (/)
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
