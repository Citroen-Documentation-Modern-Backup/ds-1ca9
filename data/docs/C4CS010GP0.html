4. Habillage
IMPERATIF : Remplacer systématiquement les agrafes défectueuses.
4.1. Charnière
Reposer :
  • Le support inférieur (4)
  • Les vis (3) ; Serrer à 1,2 ± 0,3 m.daN
  • Le support supérieur (1)
  • Les vis (2) ; Serrer à 1,2 ± 0,3 m.daN
