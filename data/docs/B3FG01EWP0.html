B3FG01EWP0Dépose - Repose : Capteur gyromètre / accéléromètre
AVEC SYSTEME ESP + TRACTION CONTROL
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Débrancher la batterie.
Figure : b3fg1dtd
Déposer la garniture (1).
Figure : b3fg1dxd
Déconnecter le connecteur  (en "a").
Déposer :
  • Les écrous (3)
  • Le capteur gyromètre-accéléromètre (2)
2. Repose
ATTENTION : Tout capteur gyromètre-accéléromètre ayant subi un choc doit être remplacé.
NOTA : Respecter le sens de montage du capteur gyromètre-accéléromètre (2) : Connecteur vers l’arrière du véhicule.
Reposer :
  • Le capteur gyromètre-accéléromètre (2)
  • Les écrous (3) ; Serrer à 0,8 m.daN
  • Connecter le connecteur  (en "a")
  • Rebrancher la batterie
3. Opérations complémentaires
À l’aide d’un outil de diagnostic :
  • Effectuer une calibration du capteur gyromètre-accéléromètre(2)
  • Faire une lecture des codes défauts et un effacement si nécessaire
