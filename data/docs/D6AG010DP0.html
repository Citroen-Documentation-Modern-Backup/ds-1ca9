D6AG010DP0Dépose - repose : Faisceaux électriques (Arrière )
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350-ZZ.
2. Opérations préliminaires
Débrancher la batterie .
Déposer : Les garnitures d’ailes arrière .
Déposer :
  • Le pare-chocs arrière
  • La garniture de porte arrière (Côté gauche )
  • Le mécanisme d’essuie-vitre arrière
  • Le 3ème feu de stop
  • La garniture de porte arrière (Côté droit )
  • Le feu arrière
3. Dépose
ATTENTION : Avant dépose : Repérer le cheminement des faisceaux.
ATTENTION : Déverrouiller les connecteurs avant de les déconnecter. À la connexion, veiller au cheminement et au bridage des faisceaux électriques.
ATTENTION : Déconnecter les connecteurs sans exercer de sollicitation ni sur les faisceaux électriques ni sur les connecteurs (Aucune traction sur les faisceaux électriques n’est admise).
Figure : d6am01dd
A : Faisceau capteurs de proximité.
B : Faisceau arrière.
Déconnecter : Les connecteurs des faisceaux électriques (1), (2).
Déclipper :
  • Les agrafes
  • Les lanières de bridage des faisceaux électriques (1), (2)
Déposer : Les faisceaux électriques (1), (2).
4. Repose
ATTENTION : Remplacer systématiquement : Les colliers de bridage ; Les agrafes défectueuses.
ATTENTION : Reposer les faisceaux (1), (2) suivant le cheminement repéré avant la dépose.
Reposer : Les faisceaux électriques (1), (2).
Clipper :
  • Les agrafes
  • Les lanières de bridage des faisceaux électriques (1), (2)
Connecter : Les connecteurs des faisceaux (1), (2).
5. Opérations complémentaires
Reposer : Les garnitures d’ailes arrière .
Reposer :
  • Les feux arrière
  • La garniture de porte arrière (Côté droit )
  • Le 3ème feu de stop
  • Le mécanisme d’essuie-vitre arrière
  • La garniture de porte arrière (Côté gauche )
  • Le pare-chocs arrière
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Vérifier le fonctionnement des équipements électriques.
