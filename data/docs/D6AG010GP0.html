1. Outillage

[1] Outils de dégarnissage (-).1350-ZZ.
2. Dépose
Débrancher la batterie .
ATTENTION : Repérer le cheminement du faisceau électrique .
ATTENTION : Déverrouiller les connecteurs avant de les déconnecter. À la connexion, veiller au cheminement et au bridage des faisceaux électriques.
ATTENTION : Déconnecter les connecteurs sans exercer de sollicitation ni sur les faisceaux électriques ni sur les connecteurs (Aucune traction sur les faisceaux électriques n’est admise).
Figure : d6am01ad
Dégager : Le faisceau électrique (1)  (boîtier de servitude intelligent).
Basculer la banquette arrière (Véhicule particulier ).
Déposer les garnitures intérieures .
Déposer :
  • Les sièges avant
  • La console centrale
  • La planche de bord
  • Les tapis de sol (Habitacle)
Déconnecter les connecteurs du faisceau électrique (1) .
Déclipper ; À l’aide de l’outil [1] :
  • Les agrafes (Du faisceau électrique (1))
  • Les colliers de bridage (Du faisceau électrique (1))
Déposer : Le faisceau électrique (1).
3. Repose
ATTENTION : Remplacer : Les colliers de bridage du faisceau électrique ; Les agrafes défectueuses.
ATTENTION : Reposer le faisceau électrique suivant le cheminement repéré avant la dépose.
Poser : Le faisceau électrique (/).
Clipper :
  • Les agrafes (Du faisceau électrique)
  • Les colliers de bridage (Du faisceau électrique)
Connecter les connecteurs .
Reposer : Les garnitures intérieures .
Reposer :
  • Les tapis de sol (Habitacle)
  • La planche de bord
  • La console centrale
  • Les sièges avant
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Vérifier le fonctionnement des équipements électriques.
