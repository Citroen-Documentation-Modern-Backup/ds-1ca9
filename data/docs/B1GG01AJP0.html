B1GG01AJP0Dépose - Repose : Radiateur de refroidissement moteur
BVM C510 OU BVM C510 PILOTE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel :
  • 1 Sangle
  • 1 Outil de levage
2. Dépose
Mettre le véhicule sur pont élévateur.
Débrancher la batterie .
Vidanger le circuit de refroidissement.
Déposer :
  • Les pare-boue avant
  • Le pare-chocs avant
  • Le refroidisseur d’air de suralimentation
Figure : b1gg0mod
Déposer le collier (1).
Désaccoupler la durit inférieure (2) du radiateur de refroidissement moteur.
Figure : b1gg0mrd
Dégrafer l’agrafe (En "a").
Déconnecter les connecteurs (3), (4).
Dégager le faisceau électrique (5) :(sur le côté).
Figure : b1gg0mud
Déposer le collier (7).
Désaccoupler : La durit supérieure (6) du radiateur de refroidissement moteur .
Figure : b1gg0mxd
Déposer le collier (9).
Désaccoupler : La durit inférieure (8) du vase d’expansion.
Figure : b1gg0myd
ATTENTION : Protéger le condenseur de réfrigération (10) avec un carton.
Déclipper : Le condenseur de réfrigération (10) (En "b").
Écarter et brider : Le condenseur de réfrigération (10) ; À l’aide de la sangle .
Figure : b1gg0n1d
Déposer :
  • Les vis (11)
  • Les supports inférieurs (12), (14) du radiateur de refroidissement moteur
  • L’ensemble radiateur- motoventilateur de refroidissement (13) (Par le dessous du véhicule) ; À l’aide d’un outil de levage
Figure : b1gg0n2d
Déposer le collier (16).
Désaccoupler la durit (17).
Appuyer sur les verrous (En "c", "d") (Effectuer l’opération de manière symétrique).
Faire coulisser (suivant flèche) le support motoventilateurs (15) sur le radiateur de refroidissement moteur (18) (Effectuer l’opération de manière symétrique).
Déposer le radiateur de refroidissement moteur (18) (Avec précaution).
Figure : b1gg0n3d
Déclipper : Le support (19) du condenseur de climatisation ; À l’aide d’une pince plate (bec fin) (En "e").
Déposer : Le support (19) du condenseur de climatisation (Suivant flèche).
3. Repose
ATTENTION : Respecter les couples de serrage .
Figure : b1gg0n6d
ATTENTION : Vérifier la présence des plots de centrage en caoutchouc (20), (21).
Figure : b1gg0n9d
ATTENTION : Vérifier la présence des plots de centrage en caoutchouc (22), (23).
Reposer : Le support (19) du condenseur de climatisation.
Clipper : Le support (19) du condenseur de climatisation (En "e").
Reposer sur le radiateur de refroidissement moteur (18), le support motoventilateurs (15).
Contrôler le verrouillage correct (En "c ", "d").
Accoupler la durit (17).
Reposer le collier (16).
Reposer :
  • L’ensemble radiateur- motoventilateur de refroidissement (13) ; À l’aide d’un outil de levage (Dans les plots de centrage en caoutchouc (20), (21))
  • Les supports inférieurs (12), (14) du radiateur de refroidissement moteur
  • Les vis (11)
Déposer : La sangle .
Clipper : Le condenseur de réfrigération (10) (En "b").
Déposer la protection du condenseur de réfrigération (10).
Accoupler : La durit inférieure (8) du vase d’expansion.
Reposer le collier (9).
Accoupler : La durit supérieure (6) du radiateur de refroidissement moteur .
Reposer le collier (7).
Mettre en place : Le faisceau électrique (5).
Connecter les connecteurs (3), (4).
Agrafer : L’agrafe (En "a").
Accoupler la durit inférieure (2) du radiateur de refroidissement moteur.
Reposer :
  • Le collier (1)
  • Le refroidisseur d’air de suralimentation
  • Le pare-chocs avant
  • Les pare-boue avant
Remplir et purger le circuit de refroidissement.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
4. Contrôle
Démarrer le moteur.
Contrôler l’absence de fuite.
Arrêter le moteur.
