C4AG010HP0Dépose - repose : Aile avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Déposer :
  • Le pare-chocs avant
  • Le pare-boue avant
  • Le projecteur
  • La grille d’auvent
Figure : c4am0cyd
Déclipper et dégager : Répétiteur d’aile (1) (suivant les flèches "a" et "b").
Déconnecter le connecteur  (en "c").
Déposer le répétiteur (1).
Figure : c4am0czd
Déposer :
  • Les vis (2)
  • L’écrou (4)
Découper les cordons de mastic ; À l’aide d’un outil tranchant.
Déposer l’aile avant (3).
Nettoyer les cordons de mastic restants.
2. Repose
Reposer :
  • L’aile avant (3)
  • Les vis (2)
  • L’écrou (4)
Connecter le connecteur  (en "c").
Reposer : Le répétiteur d’aile (1).
Effectuer le réglage des jeux et affleurements (voir opération correspondante).
Serrer :
  • Les vis (2) à 0,6 ± 0,1 m.daN
  • L’écrou (4) à 0,6 ± 0,1 m.daN
Appliquer un mastic d’étanchéité de type "A1".
Reposer :
  • La grille d’auvent
  • Le projecteur
  • Le pare-boue avant
  • Le pare-chocs avant
Vérifier le fonctionnement électrique des équipements.
