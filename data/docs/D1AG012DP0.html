D1AG012DP0Dépose - Repose : Alternateur
BVM C510 PILOTE OU BVM C510
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel : Une sangle .
2. Dépose
Placer le véhicule sur un pont élévateur.
Débrancher la batterie.
Déposer :
  • La courroie d’accessoires
  • La ligne d’échappement
Figure : d1ag02nd
ATTENTION : Lors de chaque dépose : Repérer le sens des tuyaux (2), (3) de dépression.
Désaccoupler les tuyaux (2), (3).
Déposer :
  • L’écrou (6)
  • Les vis (1), (5)
  • La réserve de vide (4) avec son support
Figure : d1ag02qd
Déposer :
  • L’écrou (9)
  • Le câble (8) de charge batterie
Repousser le câble (8) de charge batterie, sur le côté.
Déposer :
  • L’écrou (10)
  • Le câble d’excitation alternateur (7)
Repousser le câble d’excitation alternateur (7), sur le côté.
Figure : d1ag02td
Déposer les vis (11).
Basculer l’ensemble moteur-boîte de vitesses (Suivant la flèche ).
Sangler l’ensemble moteur-boîte de vitesses au châssis du véhicule ; À l’aide d’une sangle .
Figure : d1ag02wd
Déposer :
  • Les vis (12)
  • L’alternateur (13)
3. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Moteur
  • Suspension ensemble moteur-boîte de vitesses
  • Échappement
Figure : d1ag02zd
Contrôler la présence des bagues de centrage (14).
Reposer :
  • L’alternateur (13)
  • Les vis (12)
Déposer la sangle .
Reposer les vis (11).
Reposer :
  • Le câble d’excitation alternateur (7)
  • L’écrou (10)
  • Le câble (8) de charge batterie
  • L’écrou (9)
  • La réserve de vide (4) avec son support
  • Les vis (1), (5)
  • L’écrou (6)
ATTENTION : Respecter le sens des tuyaux de dépression (2), (3).
Accoupler les tuyaux (2), (3).
Reposer :
  • La ligne d’échappement
  • La courroie d’accessoires
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
