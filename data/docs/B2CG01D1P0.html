  • La batterie
  • Le support batterie
  • Le raccord du turbocompresseur
Déconnecter le connecteur de l’électropompe.

  • Le support de boîte de vitesses

4. Repose
ATTENTION : Respecter les couples de serrage.
Reposer :
  • Le groupe électrohydraulique d’actionneur
  • La vis (6)
  • La vis (5)
Déposer l’outil [0350-B].
Reposer :
  • Le support de boîte de vitesses
  • La vis (4)
  • Les vis (3)
Déposer l’outil [0350-G].
Accoupler :
  • Le tube haute pression (2)
  • Le tube de retour (1)
Connecter le connecteur de l’électropompe.
Reposer :
  • Le raccord du turbocompresseur
  • Le support de la batterie
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Reposer la batterie.
5. Opérations complémentaires
Effectuer les opérations suivantes : A l’aide de l’outil de diagnostic :
  • Purge du circuit hydraulique
  • Réglage de l’embrayage
  • Apprentissage du groupe électrohydraulique
6. Réglage de l’embrayage
6.1. Opérations préliminaires
Contrôler que la position de l’embrayage soit comprise entre 28 et 28,5 mm ; À l’aide de l’outil diagnostic.
Dans le cas contraire, effectuer un réglage.
6.2. Réglage : Position embrayage
Figure : b2bh001d
Écarter la protection (1).
Desserrer le contre-écrou (2).
Agir sur la vis (3) jusqu’à obtenir une position d’embrayage comprise entre 28 et 28.5 mm.
Serrer le contre-écrou (2).
Remettre en place : La protection (1).
