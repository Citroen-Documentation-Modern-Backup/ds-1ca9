B2CG01CPP0Dépose - Repose : Groupe électropompe
BVM C510 PILOTE
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
ATTENTION : Effectuer la mise hors pression du circuit hydraulique de pilotage de la boîte de vitesses ; À l’aide d’un outil de diagnostic.
Déposer :
  • La batterie
  • Le support batterie
  • L’écran thermique
2. Dépose
Figure : b2cg1pfd
Désaccoupler :
  • Le tube de retour (1)
  • Le tube haute pression (2)
NOTA : Obturer les tubes (1) et (2) à l’aide de bouchon afin d’éviter toute entrée d’impuretés dans le circuit hydraulique.
Figure : b2cg1pid
Déconnecter les connecteurs (3).
Figure : b2cg1pld
Déposer :
  • Les vis (5)
  • Le groupe électropompe (4)
3. Repose
ATTENTION : Respecter les couples de serrage.
Reposer :
  • Le groupe électropompe (4)
  • Les vis (5)
Connecter les connecteurs (3).
Accoupler :
  • Le tube haute pression (2)
  • Le tube de retour (1)
Reposer :
  • L’écran thermique
  • Le support batterie
  • La batterie
Effectuer :
  • Le remplissage du groupe électropompe
  • La mise en pression et la purge du circuit hydraulique ; À l’aide de l’outil diagnostic
