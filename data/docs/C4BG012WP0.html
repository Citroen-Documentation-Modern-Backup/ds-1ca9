C4BG012WP0Dépose - Repose : Volet arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap30wd
[1] Palettes de dégrafage (-).1350.
2. Opérations préliminaires
Ouvrir le volet arrière .
Débrancher la batterie .
3. Dépose
Déposer la tablette arrière .
Figure : c4bg09hd
Rabattre le ou les dossiers de siège arrière (2).
Déchausser le joint de porte : Arrière gauche  (partiellement).
Déposer (Côté gauche ) :
  • La garniture de coffre (3)
  • La garniture de custode (1)
Figure : c4bg09id
Dégrafer les connecteurs "a" ( en "b" ).
Déconnecter les connecteurs "a".
Débrancher le tube de lave-vitre (6).
Dégager (Vers l’extérieur ) :
  • Le fourreau (4)
  • Le faisceau électrique (5) - Le tube de lave-glace (6)
Figure : c4bg09jd
NOTA : Pour les opérations suivantes, 3 opérateurs sont nécessaires.
Désaccoupler : Les vérins de volet (8) ; À l’aide d’un petit tournevis.
Déposer :
  • Les écrous (9)
  • Le volet arrière (7)
4. Repose
Reposer :
  • Le volet arrière (7)
  • Les écrous (9) ; Effectuer un préserrage à 0,6 m.daN
  • Les vérins de volet (8)
Replacer : Le faisceau électrique (5) ; Le tube de lave-glace (6).
Accoupler : Le tube de lave-glace (6).
Reconnecter les connecteurs ( en "a" ).
Agrafer les connecteurs "a" ( en "b" ).
Rebrancher la batterie.
5. Réglage
Fermer le volet arrière .
Régler jeux et affleurements .
Si nécessaire : Le réglage du volet peut être complété par le réglage de la gâche du volet arrière .
Ouvrir le volet arrière .
Équilibrer les jeux et affleurements du volet arrière.
Serrer les écrous (9) à 1,5 m.daN.
Procéder dans l’ordre inverse des opérations de dépose.
Vérifier le fonctionnement des équipements.
