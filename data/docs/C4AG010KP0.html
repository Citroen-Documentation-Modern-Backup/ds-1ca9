C4AG010KP0Dépose - repose : Capot moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. Capot moteur
Ouvrir le capot moteur.
Désaccoupler le tuyau de lave-vitre (/).
Figure : c4am0jhd
NOTA : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Déposer :
  • Les vis (1)
  • Le capot moteur (2)
1.2. Bras d’articulation de capot
Figure : c4am0jjd
Déposer ( de chaque côté) :
  • Les vis (3)
  • Le bras d’articulation de capot (4)
2. Repose
2.1. Bras d’articulation de capot
Reposer ( de chaque côté) :
  • Le bras d’articulation de capot (4)
  • Les vis (3) (sans serrer)
Serrer les vis (3) et les desserrer d’un quart de tour.
Figure : c4am0jjd
Les vis (3) permettent le réglage en longueur "X" et en latéral "Y".
2.2. Capot moteur
NOTA : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Reposer :
  • Le capot moteur (2)
  • Les vis (1)
Figure : c4am0jkd
Les vis (1) permettent le réglage en hauteur "Z".
Fermer le capot moteur.
Effectuer le réglage des jeux et affleurements .
Ouvrir le capot moteur.
Serrer :
  • Les vis (3) à 2,5 ± 0,3 m.daN
  • Les vis (1) à 0,8 ± 0,1 m.daN
Accoupler : Le tuyau de lave-vitre .
Fermer le capot moteur.
Vérifier le fonctionnement des équipements.
