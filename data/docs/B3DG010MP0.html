B3DG010MP0Dépose - repose : Fusée de roue arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • La roue arrière
  • Le moyeu-roulement
  • Le segment de frein arrière
Figure : b3dm03nd
Déposer :
  • La vis (1)
  • Le capteur de roue (2)
Désaccoupler le raccord ( en "a").
Obturer les orifices de part et d’autre.
Figure : b3dm03pd
Dégrafer : Le câble de frein de stationnement ( en "b").
Déposer :
  • Les vis (4)
  • Le flasque de frein (3)
Figure : b3dm03qd
Déposer :
  • Les vis (5)
  • La fusée de roue arrière (6)
2. Repose
IMPERATIF : Respecter les couples de serrage .
Figure : b3dm03rd
Reposer :
  • La fusée de roue arrière (6)
  • Les vis (5) (enduire les vis de LOCTITE FRENETANCH)
NOTA : Alésage "c" (vers l’avant du véhicule).
Serrer les vis (5).
Reposer :
  • Le flasque de frein (3)
  • Les vis (4)
Agrafer : Le câble de frein de stationnement ( en "b").
Accoupler le raccord ( en "a").
Serrer le raccord.
Reposer :
  • Le capteur de roue (2)
  • La vis (1)
  • Le moyeu-roulement
  • Le segment de frein arrière
  • La roue arrière
Purger le circuit de freinage .
Remettre le véhicule sur ses roues.
Serrer les vis de roue .
