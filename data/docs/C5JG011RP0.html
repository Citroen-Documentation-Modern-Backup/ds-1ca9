C5JG011RP0Dépose - repose : Pare-chocs avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Déposer partiellement la partie avant du pare-boue .
Figure : c5jm076d
ATTENTION : 2 opérateurs sont nécessaires pour cette opération.
Déposer :
  • Les vis (2) (Opération symétrique)
  • Les vis (3)
  • Les vis (1)
Désaccoupler :
  • Lave-projecteur  (suivant équipement)
  • Feux de brouillard avant (suivant équipement)
Déposer le pare-chocs avant (4).
2. Repose
ATTENTION : 2 opérateurs sont nécessaires pour cette opération.
Accoupler :
  • Lave-projecteur  (suivant équipement)
  • Feux de brouillard avant (suivant équipement)
Reposer :
  • Le pare-chocs (4)
  • Les vis (1) ; Serrer à 0,64 ± 0,08 m.daN
  • Les vis (2) (Opération symétrique) ; Serrer à 0,64 ± 0,08 m.daN
  • Les vis (3) ; Serrer à 0,64 ± 0,08 m.daN
  • Le pare-boue
Vérifier le fonctionnement des différents équipements.
