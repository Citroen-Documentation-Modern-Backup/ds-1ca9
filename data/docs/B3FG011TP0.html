Déclipper la bague (19) en appliquant une pression ( en "e") ( de chaque côté) ; À l’aide d’un tournevis.

3. Repose
ATTENTION : 2 personnes sont nécessaires pour effectuer les opérations suivantes.
Reposer :
  • Le pédalier
  • Les écrous (21) ; Serrer à 2,2 ± 0,4 m.daN
  • Les écrous (20) ; Serrer à 2,2 ± 0,4 m.daN
Figure : b3fm06bd
ATTENTION : Contrôler la présence de graisse sur la liaison amplificateur de freinage/pédale de frein ; Si nécessaire, compléter par une graisse homologuée.
NOTA : Contrôler la présence de la coupelle d’appui (22).
Clipper la bague (19).
ATTENTION : Vérifier le verrouillage de la pédale de frein sur la tige de l’amplificateur de freinage.
Connecter le connecteur ( en "d").
3.1. Véhicules équipés d’une boîte de vitesses mécanique type MA
Reposer :
  • La patte (17)
  • Les écrous (15) (Sans le serrer)
  • Les vis (16)
Serrer les écrous (15).
Poser le contacteur d’embrayage (14).
Accoupler le câble d’embrayage (13) (Appuyer sur la pédale d’embrayage).

Reposer :
  • La pédale d’accélérateur (12)
  • Les vis (11)

Reposer la vis (10) ; Serrer à 2 ± 0,2 m.daN.
Connecter les connecteurs ( en "b").

  • Le boîtier de servitude intelligent (8)
  • Les vis (7)

  • La prise diagnostic (6)
  • Les vis (5)

Rebrancher la batterie.
Contrôler le fonctionnement des feux stop.
